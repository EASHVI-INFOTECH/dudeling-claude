# Security

Please don't report security problems in public issues.

Report them privately through GitHub: on this repository, open **Security → Report a vulnerability**.
You'll get a reply within 7 days, and a fix or a plan within 30 days of the report being confirmed.

Only the latest release is supported.

## What counts

Anything that lets a web page, another app or another user on the Mac read or change Dudeling's lessons,
hear the microphone, run code through Dudeling, or reach what was said on the board. Problems in Claude
Desktop itself go to Anthropic.
